# 🌿 Serene Care App

A compassionate digital wellness and mental health care companion application designed to promote peace, emotional tracking, and self-care routines. Built entirely through intuitive AI-assisted development—aka **"vibe coding"**—powered by **Google Antigravity**.

---

## ✨ Features

- **Mindfulness & Daily Check-ins:** Interactive tools to track your daily mood, thoughts, and emotional well-being.
- **Guided Exercises:** Breathing and relaxation exercises designed to lower stress and encourage mindfulness.
- **Care & Routine Tracking:** Easily manage wellness goals, self-care tasks, and daily routines.
- **Calming Minimalist UI:** A soothing interface tailored specifically to minimize cognitive load and provide a peaceful user experience.

---

## 🛠️ Tech Stack

- **Frontend / Framework:** Next.js / React
- **Styling:** Tailwind CSS
- **Database / Backend:** Supabase *(or configure based on your setup)*
- **Development Environment:** Google Antigravity (AI-driven Vibe Coding)
